# qabasone

Public presence repository for **[QabasOne](https://www.qabas.one)** / [Al Qabasy Trading](https://www.qabas.one).

QabasOne is the operational platform for Al Qabasy Trading — commerce workflows, **AlQabasyGo** logistics, and day-to-day operations, with self-hosted Odoo as the system of record.
